A revision is a change or correction to the already agreed project scope.

| Plan | Included Minor Revision Rounds |
|---|---:|
| Basic Project | 1 |
| Priority Project | 2 |
| Complete Project Package | 3 |

- Small UI changes
- Text/content corrections
- Formatting corrections
- Small bug fixes
- Minor changes to an existing feature
- Small adjustments requested after project review

### What Counts as a Major Change?

The following should generally be treated as additional work:

- Adding a completely new feature
- Adding a new module
- Changing the project concept
- Rebuilding a major part of the project
- Changing the technology stack
- Changing the project requirements after development has started
- Significant changes to functionality
- New integrations or APIs
- Any work outside the originally agreed scope

# FAQ Suggestions

## What is included in the project?

The project includes development based on the requirements agreed before project acceptance, along with the deliverables specified in the selected plan.

## How long will my project take?

The timeline depends on project complexity. Priority and Complete plans have a maximum delivery timeline of 2 months, provided all required information and feedback are supplied on time.

## Can I request changes after the project is completed?

Yes. Each plan includes a defined number of minor revision rounds. Additional revisions can be purchased as an add-on.

## What if I want to add a new feature?

New features or changes outside the agreed scope may require an additional charge. The additional cost will be communicated before the work starts.

## Does the price include printing?

No. All plans provide digital deliverables only. Printing is not included.

## Does the price include research paper publication?

No. The Complete plan includes preparation of the research paper digitally. Journal/conference submission, publication, and publication fees are not included.

## Can I get my project faster than 30 days?

Urgent delivery may be available depending on project complexity and current workload. An additional urgent-delivery charge may apply.

Yes, but highly complex projects may require a custom quote after reviewing the requirements.
